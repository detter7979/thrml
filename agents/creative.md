# thrml Creative Briefs

## Brief structure (every brief must contain)
1. Trigger reason — why was this brief created (fatigue/winner/new_concept)?
2. Hypothesis — what are we testing?
3. Target audience — specific to one segment
4. Hook — opening 3 seconds (or headline for static)
5. Core message — single benefit being communicated
6. Format — 1×1 / 9×16 / 4×5 / video
7. Visual direction — Imagen/Midjourney prompt
8. Copy — primary, headline, CTA
9. Success criteria — what does winning look like?

## Format specs (Meta-compliant)
- 1:1 Feed:    1080×1080, max 30MB, JPG/PNG
- 9:16 Story:  1080×1920, max 30MB, JPG/PNG
- 4:5 Feed:    1080×1350, max 30MB, JPG/PNG
- Reel 15s:    1080×1920, max 4GB, MP4, 30fps
- Reel 30s:    1080×1920, max 4GB, MP4, 30fps

## Composition rules (statics)
Layer 1 — Lifestyle photo (full bleed)
Layer 2 — Gradient overlay: bottom 40%, dark #1A1410 at 75% opacity
Layer 3 — Headline: DM Serif Display 64pt cream, top-left or center-bottom
Layer 4 — Subtext: DM Sans 28pt cream 80% opacity, below headline
Layer 5 — CTA pill: rust #C75B3A bg, cream text, 16pt DM Sans 600, bottom-left
Layer 6 — Wordmark: cream, top-right, 56px wide on 1080 canvas

## Variation strategy (3 per brief)
Variation A: Headline-led, smaller image emphasis
Variation B: Image-led, minimal copy overlay
Variation C: Social proof angle (star rating + quote)

## File naming
Briefs: {YYYY-MM-DD}_{trigger}_{audience}_{hook-slug}.json
Statics: static_{format}_{variation}_{generator}.png
  e.g. static_1x1_A_imagen.png, static_9x16_B_replicate.png
